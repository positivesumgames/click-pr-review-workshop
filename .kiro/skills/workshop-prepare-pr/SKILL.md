# Workshop prepare PR

Use [prepare-pr.sop.md](prepare-pr.sop.md) for this workshop's ordered procedure.
Its Python helpers run from the `workshop/` package directory in the generated
repository. Read the trusted repository's `config/review-policy.json` before
review, and [references/monitor.md](references/monitor.md) only when checks are running.

This skill does not replace `kirocrew-prepare-pr`. It grants no permission to
install/update Crew, change global configuration, start an existing gateway,
publish another repository, spend on providers, or merge.
